# ☕ 60-Day Java & Full-Stack Learning Laboratory

> **Comprehensive Java programming repository covering Core Java foundations, Object-Oriented Programming (OOP), Data Structures, Algorithms, Arrays, and String manipulation.**

---

## 📚 Study Modules

- 🧱 **`Phase1-Foundation/`**: Core Java syntax, control structures, loops, functions, and OOP principles.
- 📊 **`Array/`**: Array manipulation, multi-dimensional matrices, searching & sorting algorithms.
- 🔤 **`String/`**: String operations, StringBuilder, regex, and string algorithms.
- 📅 **`Day1/`, `Day2/`**: Daily hands-on coding challenges and practice exercises.

---

## 🛠️ Tech Stack

- **Language**: Java 17+ / Java 21
- **IDE**: VS Code, IntelliJ IDEA

---

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Omkar4812x/Java_Practice.git
   cd Java_Practice
   ```

2. **Run Java Files**:
   ```bash
   javac Phase1-Foundation/*.java
   java Phase1-Foundation.Main
   ```
